# .NET CLI cheatsheet
## Komendy

| Polecenie | Znaczenie |
|---|---|
| `dotnet --version` | Sprawdzenie zainstalowanej wersji zestawu .NET SDK. |

```bash
dotnet --version
```

| Polecenie | Znaczenie |
|---|---|
| `dotnet --list-sdks` | Wyświetlenie wszystkich dostępnych wersji SDK. |

```bash
dotnet --list-sdks
```

| Polecenie | Znaczenie |
|---|---|
| `dotnet new list` | Wyświetlenie dostępnych szablonów projektów. |

```bash
dotnet new list
```

| Polecenie | Znaczenie |
|---|---|
| `dotnet new console` | Utworzenie aplikacji konsolowej w bieżącym katalogu. |

```bash
dotnet new console
```

| Polecenie | Znaczenie |
|---|---|
| `dotnet new console -n` | Utworzenie aplikacji konsolowej w katalogu MyApp. |

```bash
dotnet new console -n MyApp
```

| Polecenie | Znaczenie |
|---|---|
| `dotnet restore` | Pobranie zależności wymaganych przez projekt. |

```bash
dotnet restore
```

| Polecenie | Znaczenie |
|---|---|
| `dotnet build` | Kompilacja projektu i odczyt komunikatów o błędach. |

```bash
dotnet build
```

| Polecenie | Znaczenie |
|---|---|
| `dotnet run` | Zbudowanie i uruchomienie wskazanego projektu. |

```bash
dotnet run --project MyApp
```

| Polecenie | Znaczenie |
|---|---|
| `dotnet clean` | Usunięcie plików wygenerowanych podczas kompilacji. |

```bash
dotnet clean
```
